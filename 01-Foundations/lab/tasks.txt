-- 01. Retrieve all columns from Production.Product.
SELECT * FROM Production.Product;

-- 02. Display only Name, ProductNumber, and Color for all products.

-- 03. Find products with a ListPrice greater than 1000.
SELECT Name, ProductID, ListPrice  FROM Production.Product
WHERE ListPrice > 1000;

-- 04. Find products that are 'Red'.
SELECT Name, Color  FROM Production.Product 
WHERE Color = 'Red';

-- 05. List products where the size is 'L'.
SELECT Name, Size  FROM Production.Product  
WHERE Size = 'L';

-- 06. Find products with a ListPrice between 500 and 1500.
SELECT Name, ProductID, ListPrice  FROM Production.Product
WHERE ListPrice BETWEEN 500 AND 1500;

-- 07. Find products where the color is NULL.
SELECT Name, Color  FROM Production.Product
WHERE Color IS NULL; -- NULL cannot be compared using the equality operator (=) --> IS / IS NOT

-- 08. Find products where the color is NOT NULL.
SELECT Name, Color  FROM Production.Product
WHERE Color IS NOT NULL;

-- 09. List all 'Silver' or 'Black' products.
SELECT Name, Color  FROM Production.Product
WHERE Color = 'Silver' 
OR Color = 'Black'; -- OR cannot be used because it returns only one of the walues if it exists

-- 10. Find products where Name starts with 'Mountain'.

WHERE Name LIKE 'mountain%';

-- 11. Find products where Name contains the word 'Bike'.

WHERE Name LIKE '%bike%';

-- 12. List all products from Production.Product sorted by Name (A-Z).
SELECT * FROM Production.Product
ORDER BY Name ASC;

-- 13. List all products sorted by ListPrice from most expensive to cheapest.
SELECT * FROM Production.Product
ORDER BY ListPrice DESC;

-- 14. Find the top 10 most expensive products.
SELECT TOP 10 * FROM Production.Product
ORDER BY ListPrice DESC; -- TOP goes right after the SELECT statement

-- 15. Find the top 5 cheapest products that are not free (Price > 0).

WHERE ListPrice > 0
ORDER BY ListPrice ASC;

-- 22. Round the StandardCost of each product to 2 decimal places.

/*
The ROUND() function is used to round a numeric value to a specified number of decimal places.
Numeric_expression: The numeric value or column you want to round
Length: The precision to which you want to round. A positive number rounds to that many decimal places.
Function (Optional): If this is 0 (default), it rounds. If it's any other value, it truncates (cuts off) the decimals instead of rounding.
Syntax: SELECT ROUND(numeric_expression, length, [function]) AS AliasName FROM Schema.TableName;
*/

-- 24. Replace 'Road' with 'Street' in the Name column of Production.Product.

WHERE Name LIKE '%Road%'; -- added WHERE clause to see the change more easily
/*
The REPLACE() function replaces all occurrences of a specified string value with another string value.
string_expression: The string or column to be searched (e.g., Name).
string_to_find: The substring to be found (e.g., 'Road').
string_replacement: The replacement substring (e.g., 'Street').
Syntax: SELECT REPLACE(string_expression, string_to_find, string_replacement) AS AliasName FROM Schema.TableName;
*/

-- 25. Use SUBSTRING to get characters 2 through 5 of the ProductNumber.

The SUBSTRING() function extracts a specific portion of a string, starting at a designated position and continuing for a specified number of characters.
expression: The string, column, or variable you want to extract from (e.g., ProductNumber).
start: An integer that specifies where the extraction starts. Note: In SQL, the first character is position 1 (not 0 like in some other programming languages).
length: A positive integer that specifies how many characters you want to take from that starting point.
Syntax: SELECT SUBSTRING(expression, start, length) AS AliasName FROM Schema.TableName;
*/

-- 31. Display the current date and time using GETDATE().

The GETDATE() function returns the current database system timestamp as a datetime value. This value is derived from the operating system of the computer on which the instance of SQL Server is running.
Syntax: SELECT GETDATE() [AS AliasName];
*/

Definition: The DATENAME() function returns a character string that represents a specific part of a date (the datepart).
The Difference: While the MONTH() function returns an integer (e.g., 7), DATENAME returns a string (e.g., 'July').
Syntax: SELECT DATENAME(datepart, date_column) AS AliasName FROM Schema.TableName;
*/

-- 37. Calculate the difference in years between BirthDate and today (Age).
SELECT * FROM HumanResources.Employee;
SELECT BusinessEntityID,
       BirthDate,
       GETDATE() AS Today,
       DATEDIFF(year, BirthDate, GETDATE() ) AS Age
FROM HumanResources.Employee;
/*
The DATEDIFF() function returns the count (as a signed integer) of the specified datepart boundaries crossed between a start date and an end date.
It calculates how many "units" (years, months, days) fit between two dates. It always subtracts the second date from the third: End - Start.
Syntax: SELECT DATEDIFF(datepart, startdate, enddate) AS AliasName FROM Schema.TableName;
*/

-- 39. Add 30 days to the OrderDate to show a 'PaymentDueDate'.
SELECT SalesOrderID, 
       OrderDate, 
       DATEADD(day, 30, OrderDate) AS PaymentDueDate
FROM Sales.SalesOrderHeader;
/*
The DATEADD() function adds a specific number (interval) to a datepart of an input date and returns the new, updated date.
datepart: The unit of time you want to add (e.g., day, month, year).
number: The value used to increment the datepart. This is an integer (positive to go forward, negative to go back).
date: The starting date or column you want to modify.
Syntax: SELECT DATEADD(datepart, number, date) AS AliasName FROM Schema.TableName;
*/

-- 41. Format the OrderDate as 'yyyy/MM/dd'.
SELECT SalesOrderID, 
       OrderDate, 
       FORMAT(OrderDate, 'yyyy/MM/dd') AS FormattedDate
FROM Sales.SalesOrderHeader;
/*
The FORMAT() function returns a value formatted with the specified format and optional culture. It is highly flexible because it uses standard .NET formatting strings.
Unlike YEAR() or MONTH() which return numbers, FORMAT() always returns a string (text) formatted exactly how you defined it.
Syntax: SELECT FORMAT(value, 'format_pattern') AS AliasName FROM Schema.TableName;
value: The date or number you want to format.
'format_pattern': A string that defines the output.
    yyyy = 4-digit year
    MM = 2-digit month (must be capital M, lowercase mm is for minutes!)
    dd = 2-digit day
*/
